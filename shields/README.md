# Shields

Shields e módulos que acoplam nas placas. A lista completa, com tags, está
no [INDEX.md](../INDEX.md).

Para adicionar um shield (teclado, display, etc.), siga o processo descrito
no [CONTRIBUTING.md](../CONTRIBUTING.md): copie `templates/item-README.md` para
`shields/<slug-do-shield>/README.md`.
